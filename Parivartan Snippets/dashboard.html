⚡ Dynamic Variables Manager

Dynamic variables are placeholders like {Page_context} or {Support_Tier} that automatically resolve to live ticket data or default values when executing AI prompts.

➕ Add New Custom Variable
{Page_context} 🔒 System Variable

Automatically captures the complete visible content, ticket messages, server diagnostics, and metadata from the active webpage or ticket portal.

{Ticket_ID} 🔒 System Variable

Extracts the ticket reference identifier (e.g., #4970144) from the portal URL query string, page header, or breadcrumbs.

{Customer_Message} 🔒 System Variable

Extracts the client's latest message or inquiry thread, isolating customer requirements from agent replies.
